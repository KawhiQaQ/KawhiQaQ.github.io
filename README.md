# Hao Tan — Academic Homepage

Personal academic website for Hao Tan (谭昊).

A static HTML/CSS/JavaScript site with no build step, external fonts, or runtime dependencies.

## Edit

- `index.html`: profile, news, education, publications, projects, intellectual property, and awards.
- `assets/style.css`: layout and styling.
- `assets/main.js`: navigation, expandable lists, and image carousels.
- `assets/contributions.js`: contribution statistics derived from the page entries.
- `assets/Hao-Tan-CV.pdf`: downloadable CV.

## Local preview

Run `python3 -m http.server 8766 --bind 127.0.0.1` in this directory, then open http://127.0.0.1:8766/.

## GitHub Pages

Publish the `main` branch from `/ (root)`. The `.nojekyll` file enables direct static serving.
